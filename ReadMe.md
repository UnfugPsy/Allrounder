# Project Allrounder - The CLI That Will Do It All (One Day™)

[![Status: Early Development](https://img.shields.io/badge/Status-Early%20Development-yellow)](https://img.shields.io/badge/Status-Early%20Development-yellow)

**Project Allrounder** is an ambitious command-line interface (CLI) with the ultimate goal of becoming your go-to tool for a wide range of tasks. While its aspirations are vast, **currently, Allrounder's sole superpower is searching Ranks for Tekken players.**

Stay tuned as we gradually unlock Allrounder's full potential, one feature at a time!

## Current Capabilities: Tekken Wavu Rank Search

Right now, you can use Allrounder to quickly look up the Wavu Rank of Tekken players.

### Usage

Open your terminal or command prompt and navigate to the directory where the `Allrounder` executable is located. Then, use the `rank` command followed by the player's steam URL (numbers only), Tekken-ID (with or without dash):

```cmd
Allrounder.exe rank "YourTekkenID"
